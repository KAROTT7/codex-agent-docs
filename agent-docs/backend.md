# 后端总则

- 先确认服务归属、模块边界、运行时版本、构建命令、数据访问、缓存、鉴权和统一异常体系。
- 路由 / Controller 负责入参出参，Service 承载业务，Repository / Mapper 负责数据访问。
- 外部输入一律视为不可信，补齐参数校验、权限、异常、幂等和日志检查。
- 处理外部调用的超时、并发、错误响应和请求生命周期。
- 优先复用现有基础设施和接口返回结构，不因个人偏好切换框架或数据访问方案。
