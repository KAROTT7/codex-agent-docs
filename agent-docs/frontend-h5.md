# H5 Web 移动端适配

本规范适用于移动端 H5 Web 应用；沿用前端总则及 CSS 规范。

## rem 适配

- 以 375px 视口宽度、16px 根字体大小为设计基准，其他元素的尺寸、间距和字体大小使用 rem 实现移动端适配。
- 移动端内容区域宽度为 `100%`，最大宽度为 `640px`，超宽视口下水平居中；固定定位的顶部栏、底部栏等也应与内容区域对齐。
- 在应用入口统一调用自定义 Hook（如 `useRem`），按 `有效宽度 = Math.min(当前布局视口宽度, 640)`、`根字号 = 有效宽度 / 375 * 16` 设置 `html` 的 `font-size`；375px 宽度下 `1rem = 16px`，视口超过 640px 后不再放大。
- Hook 在客户端初始化时设置根字号，并在视口宽度变化或屏幕旋转时重新计算；卸载时清理事件监听，避免多个页面重复注册。涉及 SSR 时，不在服务端访问 `window` 或 `document`。

## PostCSS 配置

- 使用 `postcss-pxtorem` 将样式源码中的 px 转换为 rem，配置 `rootValue: 16`、`propList: ['*']`，与根字号计算基准保持一致；已使用 rem 的样式不重复换算。
- 根字号计算结果保留 px，不纳入 px-rem 转换；检查 Tailwind、Less 及第三方样式的处理范围，确保最终产物采用一致的换算基准。JS 内联样式不会自动经过 PostCSS，应直接使用 rem 或统一转换工具。
- 640px 最大宽度限制必须保留固定 px，不转换为 rem；1px 边框等明确需要固定像素的样式也可通过转换插件支持的排除机制保留 px，其余样式仍按统一基准转换。
- 使用 `postcss-preset-env`，结合项目的 Browserslist 目标处理可转换的现代 CSS 语法及兼容前缀，提升旧浏览器兼容性；不能转换的 CSS 特性需采用目标浏览器支持的写法。
- `postcss-preset-env` 仅处理 CSS；JavaScript 语法和浏览器 API 的兼容沿用项目的转译及 polyfill 方案。
