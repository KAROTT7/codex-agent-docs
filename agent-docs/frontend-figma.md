# Figma 到代码

- 遇到 Figma 链接时，必须通过 `curl` 调用 Figma API，使用环境变量 `FIGMA_TOKEN` 鉴权并获取设计信息；不得输出 token。
- 代码实现的视觉样式必须百分之百还原 Figma 设计，包括布局、尺寸、间距、字体、颜色、边框、圆角、阴影、图标及设计中定义的交互状态，不得自行简化或替换。
- 优先复用项目现有组件和设计变量，但必须以还原 Figma 设计为前提；使用第三方组件库时，也必须覆盖与设计不一致的默认样式，包括组件内部元素及交互状态，不能以组件库默认样式作为验收标准。
- 不机械翻译 Figma 的嵌套结构；可沿用项目结构与实现方式，但不得改变设计的视觉效果。
- 多边形图案优先使用 SVG；图标直接复用设计中的 SVG icon 或项目图标库。
- 实现后，在与 Figma 设计一致的视口尺寸和状态下逐项对照页面，修正视觉差异后再交付；无法获取或确认的设计信息需明确说明，不得自行猜测并声称已完全还原。
